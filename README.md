<h1 align="center"> F1 Live Catchup </h1>

<h2 align="center"> Project Description </h2>

The ESP32 connects to the [OpenF1</sub>](https://openf1.org/) API to show the race status on display to easy catchup.

<h2 align="center"> Project Features </h2>

1. Request the data<br/>
2. Print the positions on display<br/>
3. Switch to the select pilot<br/>
4. Show the race status (flags, saftycar)<br/>

<h2 align="center"> General Information </h2>

Compiler: Arduino IDE <br/>
MCU: ESP32  <br/>
Board: Dev module <br/>
Date: 2026, Jul <br/>
